# AgentVerity Design-Partner Pilot

AgentVerity is looking for teams that need to decide whether repeated,
categorical agent behavior is strong enough to freeze as a regression
baseline. The pilot tests that narrow job on a real system; it is not a sales
programme and does not require a hosted service.

## Good fit

Your system makes a bounded decision that can be named before a run, such as a
tool choice, route, policy outcome, workflow transition, or categorical LLM
judge result. You already have repeated raw runs, or can collect independent
trials over a small reviewed case set. You have a concrete release or baseline
decision that averages alone do not settle.

This pilot is not a fit for open-ended answer scoring, general benchmarking,
production trace storage, or proving that an answer is correct or safe.

## What the pilot involves

1. A 30-minute fit and evidence-mapping call.
2. A local qualification run using saved evidence where possible. The
   participant controls any model calls and their cost.
3. A 45-minute result review covering the statistical call, route gaps,
   provenance caveats, and whether the result changed a release decision.
4. Optional publication of a sanitized evidence fixture or case study under
   terms agreed before anything is shared.

Participants receive hands-on setup help and a written findings summary. In
return, the project asks for candid workflow feedback and permission to record
anonymized fit, failure, and time-to-result measures. Publication is optional
and is never a condition of participation.

## Data and confidentiality

AgentVerity runs locally. Do not put customer prompts, model outputs,
credentials, trace identifiers, or confidential system details in a GitHub
issue. Start with decision labels and non-sensitive metadata only. Evidence is
shared only through a separately agreed channel, and a sanitized fixture is
committed only after explicit approval. See [Security and data
handling](../SECURITY.md).

## Apply

[Open a public design-partner enquiry](https://github.com/mrwersa/agentverity/issues/new?template=design-partner.yml).
The form asks only for enough non-sensitive information to assess fit. If a
public issue would reveal too much, open a minimal enquiry stating only that
you want to discuss the pilot; do not include the sensitive context.
